How It Works

7 Autonomous Agents

Each agent in the pipeline handles a specific task: ingesting raw errors, matching against historical incidents, diagnosing root causes, recommending fixes, scoring severity, routing escalations, and learning from your feedback.

1. Ingestion Agent

Extracts structured data from raw error logs using regex patterns and heuristics.

2. Matcher Agent

Compares the incident against historical KB using TF-IDF vectorization and cosine similarity.

3. Diagnosis Agent

Synthesizes a natural-language root cause explanation using Ollama Mistral LLM.

4. Severity Agent

Evaluates service criticality, confidence levels, and crisis keywords to assign P1–P4 priorities.

5. Resolution Agent

Merges and deduplicates resolution steps from matched incidents into a ranked action plan.

6. Escalation Agent

Routes alerts to owning on-call teams (`#payments-urgent`, `#sec-auth-urgent`) for immediate triage.

7. Learning Agent

Learns from feedback via a boost multiplier, making the system smarter over time.
